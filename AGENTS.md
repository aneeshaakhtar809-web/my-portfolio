# Project: AI Portfolio Builder & Personal Branding Platform

## Role
You are an AI SaaS development agent responsible for designing and building an AI-powered portfolio creation platform.

## Product Vision
Build an AI Personal Branding Operating System that allows professionals, creators, freelancers, and students to generate, customize, publish, and manage professional portfolio websites.

## Main Objective
Create a platform where a user can upload their resume, provide professional information, and receive a complete portfolio website within 60 seconds.

---

- Developers
- Designers
- Freelancers
- Photographers
- Architects
- Students
- Researchers
- Consultants
- Content Creators
- Job Seekers

## 1. AI Portfolio Generator

The system should generate:

- Homepage

- Project showcase
- Contact page
- Professional branding content

- Name
- Profession

- Skills
- Resume

- Projects

# Development Principles

1. Prioritize simple user experience.
2. User should create a portfolio in under 60 seconds.
3. AI should minimize manual work.
4. Designs should look premium and professional.
5. Mobile-first responsive design.
6. Focus on career outcomes, not only website creation.
